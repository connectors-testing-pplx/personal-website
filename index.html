01 About

Minecraft development, end to end.

I'm a Minecraft developer focused on the full stack of server customization — writing Skript for fast, readable gameplay logic, building Skript Addons in Java to extend what Skript can do, shipping Paper/Spigot plugins for performance-critical features, and wiring up Discord bots that keep communities connected to the server.

I care about code that other people can actually read and maintain: clean Skript, well-structured Java, and bots that don't fall over under load. Whether it's a single crate script or a complete server core, I build it to run smoothly and to keep running when the player count climbs.
